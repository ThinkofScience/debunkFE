# 🌍 debunkFE

Kumpulan simulasi interaktif dan materi edukasi untuk menguji klaim bumi datar menggunakan sains, geometri, dan perhitungan yang bisa dicoba sendiri.

Semua simulasi berupa file HTML mandiri yang berjalan langsung di browser, tanpa instalasi.

🔗 **Demo:** https://thinkofscience.github.io/debunkFE/

## 📚 Daftar Simulasi

| Simulasi | Deskripsi |
|---|---|
| [Perhitungan Jari-jari Bumi](simulasi_perhitungan_jari_jari_bumi.html) | Menghitung ukuran Bumi dari bayangan dan sudut matahari, seperti metode Eratosthenes. |
| [Revolusi Bumi & Hukum Kepler](simulasi_akurat_revolusi_bumi_hukum_kepler.html) | Orbit Bumi mengelilingi Matahari secara akurat menurut Hukum Kepler. |
| [Simulasi 3D Fase Bulan](simulasi_3d_fase_bulan.html) | Visualisasi 3D yang menjelaskan mengapa Bulan tampak berubah bentuk. |
| [Kalkulator Kiblat Bumi Datar](kalkulator_kiblat_bumi_datar.html) | Membandingkan arah kiblat pada model bumi datar dengan bumi bulat. |

## 🚀 Cara Menjalankan

**Online:** buka halaman demo di atas melalui GitHub Pages.

**Lokal:**

```bash
git clone https://github.com/ThinkofScience/debunkFE.git
cd debunkFE
```

Lalu buka `index.html` di browser. Tidak ada dependensi atau proses build.
